Where rules stop

  
Python decides. The model suggests.

  
Python can see that a note exists. It cannot read what the note means. That is the only gap a model is allowed to help with, and it never decides whether a case needs attention.

  

    
Python decidesIs the order closed? Is it late? How many days? Same input, same answer, and you can test it.

    
The model suggestsWhat does "Held at depot awaiting address confirmation" mean? It offers an issue family and quotes its evidence.

  


  
Try the grounding check

  
A model must quote the exact words it relied on. One line of Python catches an invented quote. Edit the quote and watch the answer.

  

    

    

      
      
      
    

    
    
    

    
Python compares text exactly, so capital letters matter. True means the quote is really in the note. False means the suggestion is not grounded.

  


  
What makes a suggestion good

  

    
Correct issue familyIt picks the right category from the declared list.

    
Grounded evidenceThe quoted words really appear in the note.

    
No invented factNothing in the summary goes beyond the note.

    
Appropriate abstentionFor "see previous" the right answer is "I cannot tell".
